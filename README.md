# PromptFolio

เว็บแอปภาษาไทยที่ช่วยนักเรียน **ม.3** สร้าง **prompt ที่ตรงจุด** สำหรับทำพอร์ตโฟลิโอเข้า ม.4 และสื่อนำเสนองานรายวิชา
ผู้ใช้ตอบคำถามง่ายๆ ทีละหน้า แล้วได้ prompt 2 ขั้นพร้อมคัดลอกไปใช้กับ ChatGPT / Claude / Gemini และ Canva / Gamma / Google Slides

ไม่มี backend ข้อมูลทั้งหมดเก็บใน `localStorage` ของเครื่องผู้ใช้

## เริ่มใช้งาน

ต้องมี Node.js 20.19+ หรือ 22.12+

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `npm run dev` | รันโหมดพัฒนา |
| `npm run build` | ตรวจ TypeScript แล้ว build ไปที่ `dist/` |
| `npm run preview` | เปิดดูไฟล์ที่ build แล้ว |
| `npm test` | รันเทสต์ของตัวสร้าง prompt และตัวตรวจ prompt |

## วิธีใช้ (สำหรับนักเรียน)

มี 2 เมนู: **สร้าง** และ **ตรวจ prompt**

**สร้าง**: ตอบคำถามทีละหน้า คำตอบบันทึกอัตโนมัติ ปิดเว็บแล้วกลับมาทำต่อได้

1. **เลือกหัวข้อ**
   - **พอร์ตโฟลิโอ เข้า ม.4**: เกี่ยวกับฉัน → จุดเด่น → ผลงานและกิจกรรม → แผนการเรียน/โรงเรียนที่จะสมัคร → หน้าตาสไลด์
   - **สื่อนำเสนองาน**: เลือกวิชา (วิทย์ คณิต ไทย อังกฤษ สังคม ประวัติศาสตร์ สุขศึกษา-พลศึกษา ศิลปะ การงานฯ วิทยาการคำนวณ โครงงาน/IS แนะแนว หรือ "อื่นๆ" แล้วพิมพ์เอง) → ประเด็นที่อยากเล่า → ผู้นำเสนอ → หน้าตาสไลด์
2. **ตอบคำถาม**: ช่องที่มีตัวอย่าง กด "ดูตัวอย่าง" ได้
3. **เลือกเครื่องมือ**: ChatGPT / Claude / Gemini หรือ Canva / Gamma / Google Slides
4. **ได้ prompt**
   - **ขั้น ก**: prompt เขียนเนื้อหาทีละสไลด์ นำไปวางใน AI แชท
   - **ขั้น ข**: prompt ทำสไลด์ นำเนื้อหาจากขั้น ก ไปวางแทนช่องสีส้ม
   - **ต่อยอด**: สั้นลง / เปลี่ยนโทน / แปลอังกฤษ / ทีละหน้า

**ตรวจ prompt**: วาง prompt ที่เขียนเอง ระบบตรวจ 8 ข้อ (บทบาท, งาน, ใช้กับอะไร, ข้อมูลตัวเอง, จำนวนหน้า/โครงสร้าง, โทน, ความยาว, ให้ AI ถามกลับ) บอกข้อที่ขาด และให้ prompt ที่เติมส่วนที่ขาดแล้ว

## แก้ไขหรือเพิ่มเนื้อหา

### เพิ่มหรือแก้เทมเพลต

แก้ `src/data/templates.json`

```json
{
  "id": "my-template",
  "title": "ชื่อเทมเพลต",
  "description": "อธิบายสั้นๆ",
  "stage": "content",
  "goals": ["present"],
  "body": "ช่วยเขียน... {{pageCount}} หน้า วิชา{{subjectLabel}}\n- ประเด็น: {{keyPoints}}"
}
```

- `stage`: `content` (ขั้น ก), `design` (ขั้น ข) หรือ `refine` (ต่อยอด)
- `{{fieldId}}` ต้องตรงกับ `id` ของช่องใน `questions.json`
- ค่าพิเศษ: `{{content}}` (ช่องวางเนื้อหาจากขั้น ก), `{{subjectLabel}}` (วิชาที่เลือก หรือที่พิมพ์เองเมื่อเลือก "อื่นๆ"), `{{deckType}}` `{{photoHint}}` (จาก goals.json), `{{audience}}`, `{{refineMode}}`
- ถ้าไม่เลือกสไตล์หรือโทนสี จะใช้ค่า "เรียบง่าย อ่านง่าย" และ "ที่เข้ากับเนื้อหา"
- ช่องที่ผู้ใช้ไม่ได้ตอบจะแสดงเป็น `[__]` ถ้าเป็นบรรทัดแบบ `หัวข้อ: {{x}}` และช่องนั้นไม่บังคับ ระบบจะตัดบรรทัดทิ้ง
- เป้าหมายหนึ่งควรมีเทมเพลต `content` อย่างน้อย 1 แบบ (ระบบใช้แบบแรกที่ตรงกับเป้าหมาย)

### เพิ่มคำถาม

แก้ `src/data/questions.json` ข้อความ `label`, `title`, `subtitle`, `placeholder`, `example` เป็นข้อความเดียว หรือแยกตามเป้าหมายก็ได้ เช่น

```json
"label": { "default": "ชื่อ-นามสกุล", "present": "ชื่อ หรือ ชื่อกลุ่ม" }
```

- ใส่ `"goals": ["m4"]` ที่หน้าหรือช่อง เพื่อให้แสดงเฉพาะหัวข้อนั้น
- ใส่ `"showIf": { "field": "subject", "equals": "อื่นๆ" }` เพื่อแสดงช่องเมื่อเลือกตัวเลือกนั้น
- เพิ่มรายวิชาได้ที่ `options` ของช่อง `subject`

## การออกแบบ

- Mobile-first ปุ่มสูงอย่างน้อย 48px ปุ่มย้อนกลับ/ถัดไปติดล่างจอ
- ฟอนต์ Prompt (หัวข้อ) + Noto Sans Thai (เนื้อหา) ขนาดพื้นฐาน 17px
- สีหลักม่วง สีรองฟ้า สีเน้นส้ม บนพื้นขาวนวล การ์ดมุมโค้ง เงานุ่ม
- Dark mode ตามระบบ และสลับเองได้ (จำค่าไว้)
- Accessibility: focus ring สีส้มชัดเจน, ลิงก์ “ข้ามไปเนื้อหาหลัก”, ย้ายโฟกัสไปหัวข้อเมื่อเปลี่ยนขั้น, error ประกาศด้วย `role="alert"`, ปุ่มตัวเลือกใช้ `aria-pressed`, รองรับ `prefers-reduced-motion`
