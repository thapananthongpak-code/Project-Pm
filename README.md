# PromptFolio

เว็บแอปภาษาไทยที่ช่วยนักเรียน ม.ต้น/ม.ปลาย สร้าง **prompt ที่ตรงจุด** สำหรับทำสไลด์แนะนำตัว พอร์ตสมัคร ม.4 พอร์ต TCAS และสไลด์นำเสนอโครงงาน
ผู้ใช้ตอบคำถามง่ายๆ ทีละหน้า แล้วได้ prompt 2 ขั้นพร้อมคัดลอกไปใช้กับ ChatGPT / Claude / Gemini และ Canva / Gamma / Google Slides

ไม่มี backend ข้อมูลทั้งหมดเก็บใน `localStorage` ของเครื่องผู้ใช้

## เริ่มใช้งาน

ต้องมี Node.js 20.19+ หรือ 22.12+

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `npm run dev` | รันโหมดพัฒนา |
| `npm run build` | ตรวจ TypeScript แล้ว build ไปที่ `dist/` |
| `npm run preview` | เปิดดูไฟล์ที่ build แล้ว |
| `npm test` | รันเทสต์ของตัวสร้าง prompt และตัวตรวจ prompt |

## วิธีใช้ (สำหรับนักเรียน)

1. **เลือกเป้าหมาย**: แนะนำตัว / พอร์ตสมัคร ม.4 / พอร์ต TCAS / นำเสนอโครงงาน
2. **ตอบคำถามทีละหน้า**: ทุกช่องมีตัวอย่าง กด “ใช้เป็นแนวทาง” เพื่อเติมตัวอย่างแล้วแก้เป็นของตัวเอง คำตอบบันทึกอัตโนมัติ ปิดเว็บแล้วกลับมาทำต่อได้
3. **เลือกเครื่องมือ**: AI แชทสำหรับเขียนเนื้อหา หรือเครื่องมือเจนสไลด์
4. **รับผลลัพธ์**
   - **ขั้น ก**: prompt เขียนเนื้อหาทีละสไลด์ นำไปวางใน AI แชท
   - **ขั้น ข**: prompt เจนดีไซน์ นำเนื้อหาจากขั้น ก ไปวางแทนช่องสีส้ม แล้วใช้กับ Canva / Gamma / Google Slides
   - **ปุ่มต่อยอด**: ทำให้สั้นลง, เป็นทางการขึ้น, เป็นกันเองขึ้น, เล่าเรื่องมากขึ้น, แปลเป็นอังกฤษ, สร้างสไลด์ทีละหน้า

เมนูอื่น:

- **เทมเพลต**: prompt สำเร็จรูป 5 แบบ ดูได้ทั้งแบบเติมข้อมูลตัวอย่างและแบบเปล่า กด “ใช้เทมเพลตนี้” หรือ “ลองกับข้อมูลตัวอย่าง”
- **ตรวจ prompt**: วาง prompt ที่เขียนเอง ระบบตรวจ 10 ข้อ (บทบาท, งาน, เป้าหมาย, ข้อมูลตัวเอง, ตัวเลข/หลักฐาน, โครงสร้าง, โทน, ความยาว, รูปแบบคำตอบ, ให้ AI ถามกลับ) แล้วเสนอ prompt ที่เติมส่วนที่ขาดให้
- **เช็กลิสต์**: รายการตรวจก่อนส่งพอร์ต ปรับตามเป้าหมาย และบอกว่าข้อไหนกรอกในเว็บแล้ว

## แก้ไขหรือเพิ่มเนื้อหา

### เพิ่มหรือแก้เทมเพลต

แก้ `src/data/templates.json`

```json
{
  "id": "my-template",
  "title": "ชื่อเทมเพลต",
  "description": "อธิบายสั้นๆ",
  "stage": "content",
  "goals": ["tcas"],
  "sampleId": "sample-tcas",
  "body": "ช่วยเขียน... {{pageCount}} หน้า เพื่อสมัคร {{target}}\n- ผลงาน: {{works}}"
}
```

- `stage`: `content` (ขั้น ก), `design` (ขั้น ข) หรือ `refine` (ต่อยอด)
- `{{fieldId}}` ต้องตรงกับ `id` ของช่องใน `questions.json`
- ค่าพิเศษ: `{{content}}` (ช่องวางเนื้อหาจากขั้น ก), `{{audience}}` (ผู้ฟังตามเป้าหมาย), `{{refineMode}}` (ข้อความจากปุ่มต่อยอด)
- ช่องที่ผู้ใช้ไม่ได้ตอบจะแสดงเป็น `[__]` ถ้าเป็นบรรทัดแบบ `หัวข้อ: {{x}}` และช่องนั้นไม่บังคับ ระบบจะตัดบรรทัดทิ้ง
- เป้าหมายหนึ่งควรมีเทมเพลต `content` อย่างน้อย 1 แบบ (ระบบใช้แบบแรกที่ตรงกับเป้าหมาย)

### เพิ่มคำถาม

แก้ `src/data/questions.json` ข้อความ `label`, `title`, `subtitle`, `placeholder`, `example` เป็นข้อความเดียว หรือแยกตามเป้าหมายก็ได้ เช่น

```json
"label": { "default": "เป้าหมาย", "tcas": "มหาวิทยาลัย / คณะ / สาขา" }
```

ใส่ `"goals": ["m4", "tcas"]` ที่หน้าหรือช่อง เพื่อให้แสดงเฉพาะเป้าหมายนั้น

## การออกแบบ

- Mobile-first ปุ่มสูงอย่างน้อย 48px ปุ่มย้อนกลับ/ถัดไปติดล่างจอ
- ฟอนต์ Prompt (หัวข้อ) + Noto Sans Thai (เนื้อหา) ขนาดพื้นฐาน 17px
- สีหลักม่วง สีรองฟ้า สีเน้นส้ม บนพื้นขาวนวล การ์ดมุมโค้ง เงานุ่ม
- Dark mode ตามระบบ และสลับเองได้ (จำค่าไว้)
- Accessibility: focus ring สีส้มชัดเจน, ลิงก์ “ข้ามไปเนื้อหาหลัก”, ย้ายโฟกัสไปหัวข้อเมื่อเปลี่ยนขั้น, error ประกาศด้วย `role="alert"`, ปุ่มตัวเลือกใช้ `aria-pressed`, รองรับ `prefers-reduced-motion`

## หมายเหตุ

- จำนวนหน้าพอร์ต TCAS (ไม่เกิน 10 หน้า) และเกณฑ์ต่างๆ ในเว็บเป็นข้อมูลทั่วไป ควรตรวจกับประกาศของคณะ/โรงเรียนจริงทุกครั้ง
- ข้อมูลใน `samples.json` เป็นตัวอย่างสมมติ
